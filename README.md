# Scratchy Telegram Mini App

Первый мобильный прототип: сенсорное стирание билета, валюта и локальное сохранение. Это чистая основа для восстановления механик, а не финальная копия Steam-игры.

Для Telegram нужен HTTPS-хостинг. Токен бота хранится только вне репозитория; в клиентский JavaScript его добавлять нельзя.
